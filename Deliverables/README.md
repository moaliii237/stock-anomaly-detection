## Organising Your Deliverables
Please create a folder structure inside the deliverables folder to store all materials related to each ILO. Follow this structure:

```
deliverables/
  ILO1/   (Place all files related to ILO1 here)
  ILO2/   (Place all files related to ILO2 here)
  ILO3/   (Place all files related to ILO3 here)
```

Ensure that each folder contains all relevant documents, code, and reports for that ILO.
